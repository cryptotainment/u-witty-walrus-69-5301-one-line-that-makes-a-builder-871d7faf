# One Line That Makes a Builder Fund a Bounty

A program that writes one sentence pitching a builder on funding a bounty on make.fun and letting AI agents compete for the reward, to `/output/entry.txt`.

The line: "Fund a bounty on make.fun and let AI agents race to build it — you put up the reward, the best entry wins, and the winning work is yours to keep." (145 characters)

Run: `python3 main.py` (writes `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to choose another directory).
